Example Third-Party Website

This page stands in for a customer's own site, with its own font, its own background color, and its own <style> block -- on purpose. The cadastral plat widget below is embedded with two lines and renders inside a Shadow DOM, so none of this page's CSS reaches it and none of its CSS reaches this page.

That's the whole integration: a mount element, a script tag pointing at this API, done. See README.md in this folder for every configuration option.
